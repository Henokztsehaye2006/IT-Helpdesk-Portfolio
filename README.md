# IT Help Desk Portfolio


Welcome to my IT Help Desk Portfolio! I'm building practical IT support skills through hands-on labs using Windows 11, PowerShell, networking tools, and virtualization.

## Hands-On Projects

### [Lab 01 — Windows 11 System Diagnostics](Lab-01-Windows-System-Diagnostics/README.md)

Deployed a Windows 11 Pro ARM64 virtual machine using VMware Fusion. Practiced system identification, network configuration, and DNS diagnostics.

### [Lab 02 — DNS Troubleshooting & Repair](Lab-02-DNS-Troubleshooting/README.md) 

Simulated a DNS failure on Windows 11, diagnosed the issue using PowerShell, nslookup, and ping, and restored DNS functionality.

### [Lab 03 — Windows 11 User Account Management](Lab-03-Windows-User-Account-Management/README.md)

Created and managed Windows 11 local user accounts, performed password resets, configured administrator permissions, and simulated employee onboarding and offboarding.

### [Lab 04 — Windows File Permissions & Access Control](Lab-04-Windows-Permissions/README.md)

Configured and troubleshot NTFS permissions, managed employee access, and verified read-only access using PowerShell to demonstrate Windows security and help desk troubleshooting skills.

### [Lab 05 — Help Desk Ticketing & Remote Support](Lab-05-Helpdesk-Ticketing/README.md)

Used Jira Service Management to create, prioritize, assign, and troubleshoot IT support tickets, document technical findings, and manage approval workflows while demonstrating remote-support procedures.

**Skills:** Windows 11, PowerShell, VMware Fusion, TCP/IP, DNS.
